# Repository Rules

- This is an SPT (Single Player Tarkov) mod.
- Do not invent SPT or EFT APIs.
- Research existing SPT code or reference projects before implementing hooks.
- Keep server-owned persistent state separate from client-side world behavior.
- Prefer supported SPT APIs/events over Harmony patches where possible.
- Keep version-specific EFT hooks isolated.
- Do not add decompiled Escape From Tarkov game code to this repository.
- Do not begin implementation until the architecture has been researched.
