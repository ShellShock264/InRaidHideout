# InRaidHideout

InRaidHideout is an open-source mod project for SPT (Single Player Tarkov).
The goal is to replace or supplement SPT's menu-based hideout with persistent
physical hideout locations inside raid maps.

The project is in the research and architecture phase. No mod implementation
has begun.

## Project organization

- `AGENTS.md`: repository rules for contributors and coding agents.
- `docs/DESIGN.md`: intended experience, scope, and open design questions.
- `docs/ARCHITECTURE.md`: architecture research and planned boundaries.
- `docs/RESEARCH.md`: verified sources, findings, and unresolved questions.
- `src/`: reserved for implementation after architecture research.
